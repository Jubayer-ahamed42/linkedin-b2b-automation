# LinkedIn Post Writer

Drafts high-engagement B2B posts optimized for founders, agency owners, and tech leaders using battle-tested 2026 hook formulas.

## Top Hook Formulas

1. **Odd-Precision Number Opener (F7)**:
   - Start immediately with a specific real-world figure or financial metric.
   - Example: *"গত মাসে ৩টি ই-কমার্স ক্লায়েন্টের ৮২.৪% কাস্টমার কোয়েরি হ্যান্ডেল করেছে একটি সিঙ্গেল এআই সেলস এজেন্ট।"*

2. **Controlled A/B Comparison (F17)**:
   - Compare traditional manual approach with automated AI architecture.
   - Example: *"টিম A: ৫ জন সাপোর্ট স্টাফ, গড়ে ১৫ মিনিট রিপ্লাই টাইম। টিম B: ১ জন ম্যানেজার + ১টি এআই এজেন্ট, ৩ সেকেন্ড রিপ্লাই টাইম।"*

3. **Platform/Category Risk (F1)**:
   - Highlight the hidden operational cost of relying on manual repetitive labor.
   - Example: *"ম্যানুয়াল ইনবক্স রিপ্লাই আপনার সেলস বাড়াচ্ছে না, বরং প্রতিদিন ৩০% প্রস্পেক্ট হারাচ্ছে।"*

4. **False-Binary Dissolve (F18)**:
   - Address common industry misconceptions (e.g., "কাস্টমার সাপোর্ট বাড়ানো মানেই কি বড় টিম হায়ার করা? মোটেও না।").

## Key Rules
- Never open with a generic question ("Are you struggling with X?").
- Deliver the core insight within the first 2 lines (before the "See more" fold).
- Keep formatting clean, mobile-optimized, and pair with a WhatsApp / DM conversation starter.
